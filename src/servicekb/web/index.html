可以问什么？

  • 故障处理：型号 + 故障码 + 现象，例如"AS-110K-HV 早上报 E037 怎么处理"。
  • 备件：料号状态、替代料号，例如"310-04521-B 停产了吗？用什么替代"。
  • 拍照识别：点"添加照片"拍零件或铭牌，系统先识别料号，再用知识库回答。

每个回答都标注了来源 1，点开可以核对原文。知识库里没有依据时，系统会直接说明并标记"需升级"，而不是编一个答案。 回答不对时请点"没用"或"纠正答案"——专家的修正会用来改进知识库。每个问题独立回答，暂不支持连续追问。
